# 🧮 CodeAlpha Calculator

A responsive and interactive calculator built using **HTML**, **CSS**, and **JavaScript** as part of the **CodeAlpha Frontend Development Internship**.

## 🚀 Features

- Addition, Subtraction, Multiplication, Division
- Percentage Calculation
- Keyboard Support
- Clear & Backspace
- Responsive Design
- Modern User Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
